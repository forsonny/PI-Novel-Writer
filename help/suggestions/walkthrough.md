# /PNW-suggestions — Walkthrough

1. In supervised editing, create proposals with `edit_suggest`.
2. Run `/PNW-suggestions` and copy the exact displayed ID.
3. Accept, reject, or modify one pending item at a time. Re-read the scene before
   accepting old suggestions; exact matching protects against stale prose.
4. If acceptance fails, leave the item pending until you reject it or replace it
   with a new proposal.
5. Refresh affected summaries and continuity records after accepted changes.

The command does not display full history. Read the local suggestions record when
an accepted/rejected audit is needed. No automatic queue cleanup is performed.
