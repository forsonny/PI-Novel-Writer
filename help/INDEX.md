# pi-novel-writer Help Index

## Commands

Setup and navigation: `/PNW-init`, `/PNW-load [path]`, `/PNW-status`, `/PNW-help`,
`/PNW-next`.

Story records: `/PNW-bible`, `/PNW-outline`, `/PNW-summarize` with optional scene
or chapter arguments.

Writing and editing: `/PNW-sprint [minutes]`, `/PNW-edit`, `/PNW-suggestions`,
`/PNW-progress`, `/PNW-compile`.

Autonomous writing: `/PNW-auto start <brief>`, `status [full]`, `pause`, `resume`.

GitHub: `/PNW-github`, `/PNW-github-connect <url>`, `/PNW-github-push [message]`,
`/PNW-github-pull`, `/PNW-github-clone <url> [directory]`.

Each maintained command folder contains `help.md`, `walkthrough.md`, and
`resources.md`. `/PNW-help` is the live alphabetical command list. The main README
covers installation and autonomous operation.

## Guided workflows

Available workflows cover getting started, import, premise, world building,
character interviews, novel/chapter outlines, scene drafting, retroactive outline,
developmental/line/copy editing, continuity, voice matching, GitHub setup, and the
autonomous novel route. Supervised workflows ask for author approval where stated;
an authorized autonomous run makes delegated creative choices without milestone or
per-edit approval.

## Important limits

Freshness checks are mechanical, not factual validation. Existing project guidance
does not update automatically. Delete tools archive scenes/bible entries, while
merge removes its second active scene only after archiving both originals. GitHub
connect can force-push; export is Markdown plus optional DOCX only.
