# /PNW-next — Walkthrough

Run `/PNW-next` when you want a suggestion, then verify its premise:
- use `/PNW-bible` for entry count;
- use `/PNW-outline` for chapter outlines;
- use `/PNW-status` for actual scene words and numeric gaps;
- use `novel_summary_refresh` for missing or stale scene/chapter summaries;
- use `/PNW-suggestions` for pending collaborative edits.

Treat the stage as navigation, not a completion gate. A missing bible can mask later
work, a present summary can be stale, and polished/final labels do not prove review.
Autonomous writing uses its own saved phase and evidence gates; check `/PNW-auto
status` instead.
