# /PNW-status — Help Reference

`/PNW-status` reads every discovered scene body, totals words, groups scenes by
chapter, and reports numeric chapter/scene gaps. It shows title, genre, POV, tense,
target progress, chapter count, scene count, and current-session usage when Pi
provides it.

It does not read outline titles, daily goals, summaries, bible coverage, pending
suggestions, or semantic project health. Outline-status scene prose is included in
the word total. Chapter “dominant” status is the middle value after alphabetically
sorting status names, not a workflow-completion calculation.

Use `novel_summary_refresh` for summary freshness, `/PNW-next` for heuristic next
steps, and `analyze_wordcount` for machine-readable exact totals.
