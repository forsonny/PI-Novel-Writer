# /PNW-help — Help Reference

`/PNW-help` works without a loaded novel. It reads the commands currently
registered in Pi, keeps names beginning with `PNW-`, sorts them alphabetically,
and prints each command with its registered description.

The output is not grouped by workflow stage and does not include AI-callable tools.
It includes autonomous and GitHub commands when those extensions loaded correctly.
Use `help/INDEX.md` for a curated overview and each command folder for detail.
