# /PNW-help — Resources

The help command dynamically lists registered `/PNW-*` commands. It does not read
these help documents, inspect a novel, or verify that a command's deeper behavior
matches prose documentation.

Maintained help folders cover init, load, status, bible, outline, edit,
suggestions, compile, progress, sprint, help, next, summarize and GitHub. The
single `/PNW-auto` command is documented in the main README and autonomous-novel
workflow.
