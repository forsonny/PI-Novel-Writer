# /PNW-help — Walkthrough

1. Run `/PNW-help` for the live alphabetical command list.
2. Run `/PNW-next` for a heuristic suggestion based on the loaded novel.
3. Read `help/INDEX.md` or a command's `help.md` for maintained guidance.
4. If behavior differs from an example, trust the current command output and the
   explicit limitations in its help file rather than illustrative sample data.
