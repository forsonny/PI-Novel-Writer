# /PNW-outline — Resources

Chapter files use `outline/chapters/01-title.md` with frontmatter such as chapter,
title, POV, locations, timeline, purpose, target words, emotional arc,
plot threads and scene count.

`outline_chapter_create` writes a full metadata set and preserves an existing body
when no new body is supplied. `outline_chapter_update` preserves unspecified
metadata and can update body/title/timeline/scenes. `outline_scene_card_create`
replaces or appends `## Scene N` and raises scene count when needed.

Outlines are not automatically injected as story context by the current writing
context block. Read the current chapter explicitly before drafting.

Planning records must distinguish planned and actual events. Reconcile changed
dates, counts, custody, resources and order across the current header, scene card,
master plan and actual timeline/continuity records. Archive or label superseded
plans; future plans are not canon.
