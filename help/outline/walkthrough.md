# /PNW-outline — Walkthrough

1. Create chapter outlines in supervised work with author approval, or let an
   authorized autonomous run make delegated creative choices.
2. Read the chapter explicitly before drafting; `/PNW-outline` is only a compact
   title/purpose list.
3. Add/update scene cards sequentially. Update chapter title, timeline and scene
   count through `outline_chapter_update` when they change.
4. After prose diverges, reconcile dates, counts, custody, resources and event
   order in the header, card, master plan and actual records. Clearly mark the old
   plan superseded instead of leaving two unlabeled current versions.
5. Never treat a future card as evidence that the event occurred.

Avoid chapter reorder for insertion unless you are prepared to repair all affected
references manually; it does not shift a range of chapters.
