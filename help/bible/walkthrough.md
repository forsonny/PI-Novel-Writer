# /PNW-bible — Walkthrough

1. Build focused entries with the world-building or character-interview workflow,
   or ask the AI to call `bible_create` directly.
2. Use `core` only for load-bearing entries, `secondary` for normal recurring
   material, and `minor` for occasional reference.
3. Run `/PNW-bible` to review what exists and `bible_read` for full details.
4. Update living entries as the story changes, but keep historical state and
   future plans clearly labeled. Do not replace actual history with the latest
   condition alone.
5. Use `context_summary` before drafting to see what automatic context selected.
   Read omitted load-bearing entries explicitly.
6. Treat `bible_consistency_check` as a synchronization-date warning only. Verify
   names, dates, knowledge, custody, resources and rules against prose and actual
   records; mechanical freshness is not factual accuracy.

Archive obsolete entries with `bible_delete` only when you want them removed from
normal lookup. The archived copy remains recoverable.
