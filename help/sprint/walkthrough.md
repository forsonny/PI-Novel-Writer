# /PNW-sprint — Walkthrough

1. Choose the scene or editing task first.
2. Run `/PNW-sprint` or `/PNW-sprint <positive minutes>`.
3. Work while the footer counts down.
4. At expiry, read the net word change and WPM. For editing, a flat or negative
   count can be expected.
5. Run `/PNW-progress` separately for daily and total targets.

The sprint is a local timer, not an autonomous writing command. It does not create
prose, persist sprint history, or guarantee cancellation from a normal message.
