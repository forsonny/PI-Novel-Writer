# /PNW-edit — Walkthrough

1. Run `/PNW-edit` if you want the session notice.
2. Read the target scene and its intended function.
3. Ask for one or more evidence-based analyses. Treat the response as AI judgment,
   not a computed score or human-reader result.
4. In supervised work, queue exact changes with `edit_suggest`, then review them
   through `/PNW-suggestions`. Apply direct line edits only when authorized.
5. In an authorized autonomous run, justified edits are applied directly rather
   than waiting for per-edit approval; prior prose is still retained.
6. Refresh affected summaries and continuity records after prose changes.

Status labels are author-controlled workflow markers. Changing a label does not
prove an editing pass occurred or update story records automatically.
