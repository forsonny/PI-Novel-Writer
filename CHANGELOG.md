# Changelog

## 0.3.0-rc.1 - local release candidate, 13 September 2026

This is a software implementation of the supplied Beyond Fluency control design,
not a claim that the proposed framework has passed its novel-scale benchmark.

Added managed collaborative/delegated/research governance; preview-bound project
and guidance migrations; stable scene identity; content-addressed prose/state
snapshots; source-bound summaries and suggestions; conditional AVS compilation;
separate narrative/style context; epistemic memory; promise/motif/affordance
registries; bounded no-tool model workers; functional alternatives; evidence-first
reconstruction, diagnosis, revision and comparison; protected interpretations;
chapter/arc/manuscript audits; report-only conditional drift; budget reservation,
interruption recovery and whole-snapshot restoration. Added working versus
accepted-snapshot export, actual evidence coverage, runtime schema exports and
offline evaluation/ablation records with separate private decoding keys.

Hardened scene metadata/path handling and Git publication. Removed token-bearing
remotes, shell interpolation, blanket publication staging and automatic force
push. Repository backup/publication requires explicit preview and remains outside
autonomous creative delegation. Removed temporary development CI write/patch
transport from the release candidate.

Compatibility: managed mode is opt-in. Existing manuscript words, custom guidance
and unknown metadata are not rewritten on load. Legacy workflows remain available.
New line edits and suggestions require the source hash actually read; old
unversioned suggestions must be reproposed. Node >=22.19.0 and Pi 0.85.1 are the
declared baseline; dependency versions are pinned for development.

Verification: see `docs/implementation-status.md` and individual reviews. Local
mock-host and storage checks do not establish live provider behavior, operating
system coverage, human literary quality, or empirical calibration. No npm release,
GitHub merge, external publication or paid benchmark is implied by this file.
