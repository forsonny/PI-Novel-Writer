# Structural schemas

Generated from `extensions/llgf/catalogue.ts` and its TypeBox runtime sources.
Run `npm run schemas` after a contract change; `npm run schemas:check` rejects
stale exported files. The test suite compares every file to the runtime source.

JSON structural validity is necessary but insufficient. Evidence-span bounds,
source hashes, epistemic modality, temporal acquisition, authority, source rights,
state graph relationships, budget reservations and commit consistency require the
corresponding TypeScript domain validators. Do not use these JSON files alone to
promote extracted state or certify a manuscript. No schema is a literary metric.

These are this extension's implementation, not files claimed to have been
imported from the dissertation's separate reproducibility archive. Versions are
explicit. Old projects are not rewritten simply by loading a schema.
