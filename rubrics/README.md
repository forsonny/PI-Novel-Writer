# Contextual diagnostic cards

`pattern-cards.json` paraphrases the supplied *Beyond Fluency* dissertation
(11 September 2026), Chapter 5 pp. 54-63 and Appendix B pp. 188-199, using the
reviewed blueprint crosswalk. It preserves all 56 Chapter 5 subtypes and maps them
to 48 Appendix B families. Definitions and proposed routes are an implementation
interpretation, not validated detectors or a direct import of absent reference code.

CF1-CF8 are Appendix B **family-level candidate causes**, not empirically identified
causes for a particular sentence or finer subtype. The separately retained
Chapter 5 cause namespace is not silently converted. A critic must seek actual
workflow evidence, report uncertainty, and preserve intentional effective forms.

The diagnostic worker receives the definitions, evidence questions, interventions
and paired risks. A scoped revision receives only relevant cards. The drafter does
not receive the entire card bank. Cards never automatically reject prose or infer
who wrote it. Long-range claims need long-range evidence. Genre, viewpoint and
scene function may license any ordinarily criticized form.
