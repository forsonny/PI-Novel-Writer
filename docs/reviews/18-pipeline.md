# Change 18: executable scene pipeline and acceptance gateway

Connected preparation, isolated role calls, bounded append-only drafting, state
extraction, diagnostics, multidimensional validation, selective revision, randomized
revision comparison, immutable evidence, and atomic accepted snapshots. Preparation
and all intermediate candidates remain provisional. A failed gate leaves the
working manuscript and accepted snapshot unchanged. Model call allowances are
reserved before execution and private records survive failure. The original source,
settings and accepted snapshot are rechecked at execution and acceptance.

Review repaired an overly small task-payload bound for full-scene comparisons,
strict-schema intersection in blind comparison, an O(n-squared) state retrieval
scan, interrupted acceptance replay, and persistence of exact-span rebases across
resume. Exact protections are rebased by the validated patch offsets, not fuzzy
search; the original and revised contract remain in the evidence history.

Verification: syntax, strict TypeScript and 85 regression tests pass locally.
Five integrated mock-provider tests cover review-to-accept, bounded continuation,
failed information permissions, stale/unauthorized calls, and commit-recovery
without overwriting a later author edit. No live model or human study was run.
The gateway reports model assessments, not guaranteed literary or semantic truth.
Working Markdown is a recoverable projection of accepted state. UI commands and
whole-manuscript scheduling are the next integration step.
