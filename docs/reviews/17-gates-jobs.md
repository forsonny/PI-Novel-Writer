# Change 17: Multidimensional gates and durable call budgets

Implemented source-bound scene validation covering eight dimensions, contract obligations, information permissions, protected properties, state decisions, and exit states. Gates distinguish uncertainty and intentional narrative contradictions, protect all ambiguity readings, keep human checkpoints separate from delegated model review, and return repair decisions instead of an aggregate score.

Calls reserve a durable token/call allowance before execution. Interrupted reservations retain their cost allowance and require explicit inspection. Disk state never supplies execution permission. Hard monetary caps are rejected when reliable pricing is unavailable rather than treating unknown prices as free.

Review: 80 regression tests and strict typechecking pass. Tests cover missing evidence, withheld information, protected ambiguity, human-review boundaries, interrupted reservations, stale job identity, and exhausted budgets. Review tightened positive checks to require current-text evidence and prevented a positive result hiding an unresolved error. Exact wording and semantic protection are checked separately. Fixed a Node strip-types incompatibility before acceptance.

Limitations: model validation is an evidence-linked assessment, not independent literary judgment. Reserved token counts are conservative allowances, not invoices. The store is not a hostile-process sandbox.
