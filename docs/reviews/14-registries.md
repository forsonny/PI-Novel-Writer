# Change 14: promises, motifs and language affordances

Added typed, source-verified promise and motif histories, explicit transformations,
nonresolution, reopening, dormancy and reactivation. Updates return immutable copies
and enforce idempotent event IDs. Reading positions are separate from event IDs.
Aging and saturation are review signals, never mandatory reminders or insertion
quotas. Source spans attach changes to actual prose. Documented omission and
nonresolution can record a rationale without pretending an absent span exists.

Language affordances require approved, current, viewpoint-available grounding state,
matching conditions, explicit provider transmission and permitted rights. This extra
availability set was added during review: a current world fact is not automatically
knowledge available to the focalizer. Calibration labels require supporting records.

Verification: 68 tests, syntax and strict TypeScript checks pass. New tests cover
source corruption, replay, immutable updates, premature resolution, intentional
nonresolution, dormancy, transformed meaning, saturation, viewpoint access, stale
state and transmission permission. Literary salience and image aptness are still
interpretive judgments, not properties proved by event validation.
