# Change 16: protected, dependency-aware revision

Added typed minimal patches tied to source hash, scene, diagnosed ranges and pass.
The planner schedules only supported passes, in dependency order, and returns state,
plan and context repairs separately. Exact wording is protected mechanically;
implications, silence, voice and alternative readings require separate whole-text
assessment. A comparison may keep the source or tie. Missing checks, lost readings,
paired-risk failures, regressions and forged human attribution deny acceptance.

Review corrected adjacent-patch handling and added candidate-body integrity checking.
Semantic review is explicitly model-assisted or human, never a claimed deterministic
proof. Exact spans must be explicitly rebased after their source version changes.
Recovery detects repeated failures and A/B oscillation. No generic polish pass runs.

Verification: syntax, strict typecheck and 76 tests pass locally. New tests cover
source drift, scope/budget overrun, exact protection, ambiguity lost despite intact
wording, absent semantic checks, no-diagnosis no-op, and bounded recovery. Numeric
edit budgets are engineering defaults, not empirically validated literary thresholds.
